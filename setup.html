What it is
Not a CRM. A rhythm.

Most contact tools ask you to manage data. Small Circles asks you to maintain relationships. The only rule: every contact should always have a next action date. Not a pipeline. Not a score. Just your people, your rhythm, and a clear answer to one question — who do I call today?

Getting set up
Five steps. About 15 minutes.
  • 1
    Create a free GitHub account
    GitHub is a free website that stores files and publishes them as live web pages. Sign up with your Google account — no coding knowledge needed.
    github.com → Sign up
  • 2
    Create a new repository
    Click the + button in the top right → New repository. Name it small-circles. Set it to Public, check "Add a README", click Create.
  • 3
    Copy and paste the code
    Click the button below to open the app code on GitHub. Click "Copy raw file" (the copy icon near the top right). Back in your new repository, click Add file → Create new file. Name it index.html, paste the code, and click Commit changes.
    Open the code on GitHub →
  • 4
    Enable GitHub Pages
    Inside your repository, click Settings → Pages in the left sidebar. Under Branch, select main and click Save. Wait about 60 seconds.
  • 5
    Bookmark your personal URL
    Your app is now live. Bookmark it and add it to your phone's home screen as a web app.
    yourusername.github.io/small-circles

The one rule
Pick one browser on one device

Your contacts save automatically to whichever browser you use on whichever device you use. Chrome on your laptop works well. Stick to that one place and everything persists perfectly. Opening the app in a different browser or on a different device will show a fresh copy — your data won't follow you until you set up cross-device sync (see below).

Make it your own
Built to be customized with Claude
Don't like something? Change it in 30 seconds.

Small Circles was built using Claude, Anthropic's AI assistant — and that means it's designed to be modified by anyone, no coding required. Take your index.html file to claude.ai, describe what you want, and Claude will update the code for you. Paste it back into GitHub and you're done.

Want it everywhere?
Cross-device sync — free upgrade

By default your contacts save to your browser on one device. To sync across your phone, laptop, and anywhere else, you can connect Small Circles to a free database called Supabase. Setup takes about 15 minutes and costs nothing.

The easiest way: go to claude.ai and say "Help me add Supabase sync to my Small Circles app." Claude will walk you through every step.
